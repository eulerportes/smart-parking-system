# Smart Parking System (Python + IoT + LPR)

## Overview
This project is a real-world smart parking system that integrates License Plate Recognition (LPR), IoT devices, and a Python-based backend for automated vehicle management.

## Features
- Automatic vehicle detection using LPR cameras
- Real-time event processing and deduplication
- Parking occupancy control
- Ticket generation (PDF/Excel)
- IoT integration (Shelly devices for gate control)
- Multi-location support (front/back parking lots)

## Technologies
- Python (Flask, PySide6)
- REST APIs
- Event-driven architecture
- IoT integration
- Excel and PDF reporting

## How it works
1. Camera detects license plate  
2. Event is sent to backend  
3. System processes entry and exit  
4. IoT device triggers gate control  
5. Data is logged and reported  

## Use Case
Designed for real-world parking automation, reducing manual processes and improving operational efficiency.
